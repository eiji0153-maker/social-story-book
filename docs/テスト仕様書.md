# SocialStory Book テスト仕様書（MVP）

要件定義書「4. 機能要件（FR-1〜FR-8）」の**必須機能**に対する、
「何をしたら、どうなるべきか」のテストケース一覧。
`data-testid` はE2E自動テスト（Playwright）と対応する。

## 前提
- 各テストはクリーンな状態（localStorageを初期化）から開始する。
- 対象ブラウザ: Chromium（Playwright）。

---

## FR-1 ブック管理

| ID | 何をしたら | どうなるべきか | testid |
|----|-----------|----------------|--------|
| T-1-1 | 初回アクセスする | 「まだ えほんが ありません」が表示される | `empty-message` |
| T-1-2 | 「あたらしい えほんをつくる」を押す | エディタ画面に遷移し、タイトルが「あたらしい えほん」になっている | `create-book` / `editor` / `book-title` |
| T-1-3 | エディタで「一覧へ」を押す | 一覧に戻り、作成したブックが1件表示される | `back-to-list` / `book-card` |
| T-1-4 | 一覧のブックを開く | そのブックのエディタが開く | `open-book` |
| T-1-5 | 一覧で「削除」を押し確認する | そのブックが一覧から消える | `delete-book` |
| T-1-6 | 保存後にページを再読み込みする | 保存したブックが一覧に残っている | `save-book` |
